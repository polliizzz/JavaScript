Лабораторний проєкт: PinkFlix (Фільмова база)
Опис проєкту

PinkFlix — односторінковий веб-застосунок для перегляду серіалів із TVMaze API. Проєкт демонструє роботу з асинхронними запитами, DOM-маніпуляціями, фільтрацією та сортуванням даних.

Основний функціонал:
Завантаження даних із API (async/await)
Відображення серіалів у вигляді карток
Пошук за назвою
Фільтрація за жанрами
Сортування:
за рейтингом
за назвою
Обробка помилок запиту
Адаптивний інтерфейс

Технології:
HTML5
CSS3 (pastel / pink theme)
JavaScript ES6+
Fetch API

Структура:
index.html — структура сторінки
style.css — рожевий UI стиль
app.js — логіка застосунку

Логіка роботи:
Завантаження даних при старті
Збереження даних у state
Фільтрація (пошук + жанр)
Сортування (назва / рейтинг)
Ререндер DOM

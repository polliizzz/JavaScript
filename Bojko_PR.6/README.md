# Практична робота №6
## Тема: Модульна система та сучасні можливості ES6+

---

## Мета роботи

1. Ознайомитися з принципами модульної системи JavaScript.
2. Навчитися використовувати import/export.
3. Освоїти можливості ES6+:
   - стрілочні функції
   - шаблонні рядки
   - деструктуризацію
   - spread/rest оператори
   - enhanced object literals
   - default parameters
4. Розробити невеликий модульний проект.

---

## Структура проекту

- index.html — головна HTML сторінка
- style.css — стилі інтерфейсу
- script.js — основний модуль
- utils.js — бібліотека утиліт
- data.js — дані додатку

---

## Використані технології

- ES6 Modules
- Arrow Functions
- Template Literals
- Destructuring
- Spread / Rest Operators
- Default Parameters
- Enhanced Object Literals

---

## Як запустити проект

ES6 модулі не працюють через пряме відкриття HTML файлу.

Для запуску використовуйте:

### Варіант 1
Розширення Live Server у VS Code

Практична робота №5 з теми асинхронне програмування в JavaScript.

Проєкт демонструє роботу з:

Fetch API
Promises
async/await
обробкою помилок (try/catch)
API запитами (JSONPlaceholder + PokeAPI)

Функціонал
1. Завантаження користувачів
Виконується запит до:
https://jsonplaceholder.typicode.com/users
Дані виводяться у форматі JSON (JSON.stringify)

2. Пошук покемона
Користувач вводить ім’я або ID через prompt
Виконується запит до:
https://pokeapi.co/api/v2/pokemon/{name}
Відображається картка покемона:
ім’я
зображення
типи
XP
HP

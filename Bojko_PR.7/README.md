# Практична робота №7

## Тема
Робота з даними: JSON, localStorage та обробка інформації

---

## Реалізовано

- Робота з JSON.parse() та JSON.stringify()
- Збереження даних у localStorage
- Методи масивів:
  - map()
  - filter()
  - reduce()
- Обробка помилок через try/catch
- Інтерактивний To-Do List
- Делегування подій
- Адаптивний дизайн
